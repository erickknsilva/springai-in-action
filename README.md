Resumo
A geração aumentada por recuperação (RAG) permite que as aplicações enviem prompts que solicitam informações para as quais o LLM não foi treinado.
O RAG também pode reduzir muito as chamadas alucinações que ocorrem quando o modelo não é treinado em um tema ou está supertreinado e não consegue discernir o contexto.
O RAG funciona focando o contexto do prompt em alguns documentos semelhantes à pergunta que está sendo feita.
O Spring AI inclui integração com mais de uma dúzia de lojas vetoriais para armazenar e consultar documentos semelhantes à pergunta feita.
